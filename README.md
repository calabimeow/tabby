tabby is a MonoGame-like framework for developing games and other applications in C.

features
-------

- 100+ functions for drawing, input, sound, etc

- Supported on Windows and Linux


dependencies
-------
- gcc



example
-------

Write `tabby newproj [projectname]` in your console to create a new project in tabby's folder



Write `tabby compile run [projectname]` to automatically compile and run the app



Then you can write `draw_rect(0, 0, 100, 100, RED);` in `tabby_draw()` function inside your project's C file to draw a rectangle on the screen



Check `tabby.h` for all available functions
